# Changelog

## Unreleased
- Blender export preserves exact mesh element and loop order, custom attributes and normals, and bit-exact object world matrices; the realistic Boolean/Decimate/Solidify stack now matches at each modifier prefix, with a Blender-gated non-natural edge-order round trip regression.
- `pot render` treats an enabled but empty sequencer as a no-op, uses the scene camera, and ignores unsupported audio codecs for image output; Blender-import regressions cover default-scene rendering and strict feature errors on the realistic scene.
- Blender round trips preserve world display/background colors, area-light shape and dimensions, curve resolution and material slots, and per-view hide state independently from global visibility flags.
- Blender import stores native Surface Deform, Mesh Deform, and Laplacian Deform bind arrays in `Modifier.binding_data`. Laplacian evaluation matches Blender within 1e-5 for deformed bind states, repeated rotation solves, and hook-moved anchors; export reuses unchanged native bindings from the original compatibility `.blend`, with geometry/settings checked after reopen.
- Native Surface Deform binds now map Blender's evaluated target vertex order (including modifier stacks and shape keys) into the evaluated operand mesh, use the bind-time target-to-owner transform, and skip with typed topology warnings when target vertex or polygon counts change; Blender regressions cover subdivision, Array, transforms, and Potter binding against modified targets.
- Modifier binding evaluates only its required mesh-dependency closure; preview skips unsupported objects with typed `feature_id` warnings, while whole-scene inspect returns per-item evaluation errors and targeted inspect remains typed.
- Breaking: modifier and constraint `params` now use Blender RNA property names and uppercase enum identifiers. Renamed modifier params include Array `relative_offset`/`constant_offset` → `relative_offset_displace`/`constant_offset_displace`, Mirror `axis`/`merge` → `use_axis`/`use_mirror_merge`, Weld `distance` → `merge_threshold`, Warp `from_object`/`to_object` → `object_from`/`object_to`, Volume To Mesh `iso_level` → `threshold`, Armature `armature` → `object`, and Mesh Sequence Cache `read`/`interpolate` → `read_data`/`use_vertex_interpolation`; unknown per-type params and enum values now fail validation.
- Breaking: `node.create` primitive params now use Blender operator RNA names and enum values; cylinder/cone cap fill, circle fill, torus radius mode, and per-primitive operator schemas are supported, and non-geometry kinds accept empty `params` objects.
- Geometry Nodes evaluate mesh primitives with node-native sockets and semantics, separately from `node.create` operators: Cube's vector Size/XYZ vertex counts, Grid's unit-size/vertex-count defaults, UV Sphere's phase, Cylinder/Cone layouts (Cone spans Z=0 to Depth), Circle/Line geometry, Ico Sphere support, and signed/zero dimensions follow Blender's node behavior.
- Icosphere subdivision now matches Blender's single-pass multicut vertex and face ordering and float32 sphere projection at subdivision levels 1–5.
- Boolean DIFFERENCE now subtracts disconnected cutter components independently; Blender-gated strict geometry regressions cover separated, face-touching, and top-coplanar array-box cutters with manifold, component, 1e-5 surface, and 1e-6 relative-volume checks.
- Mesh-reading modifiers and geometry constraints now consume dependency-ordered evaluated operand meshes at the current frame; detected operand cycles return `EVALUATION_FAILED` instead of silently using base geometry.
- Blender export correctly recognizes linked mesh data and preserves the output path while restoring shape-key actions, allowing Alembic Mesh Cache and Transform Cache round trips to complete.
- Blender spot-light export keeps the shared math module available throughout scene restoration; a Blender-gated round trip verifies spot size and blend.
- Blender 5.2.2 Boolean surfaces match within 1e-5, but EXACT/FLOAT solver topology is not reproduced; enabled topology-dependent suffixes and applying a Boolean ahead of such a suffix now report `modifier.boolean.downstream_topology`, also listed as not supported in the feature catalog.
- Blender 5.2 F-Curve imports preserve resolved Bezier handle coordinates and invert time-axis cubic segments during sampling, fixing transform and animated Follow Path parity.
- Blender Key-datablock shape-key actions, muted keys/FCurves, relative weights, and linear interpolation now evaluate on mesh data; Surface Deform operands consume the evaluated target, with Blender-gated 1e-5 target and bound-mesh parity coverage.
- Blender bevel profiles use superellipse chord spacing and face-space offsets; four-or-more-edge vertices with multiple beveled edges now report `modifier.bevel.high_valence_vertex_mesh` instead of approximate geometry, cataloged unsupported and covered by the gear-stack prefix regression.
- Exact Boolean BSP traversal uses explicit worklists instead of recursive calls, preventing stack overflow on tilted cylinder cutters; regression coverage verifies the resulting box bore remains closed and removes volume.
- Armature modifier skinning now converts between mesh and armature object spaces before applying bone matrices, preserving weighted deformations when rig and mesh share a world offset.
- Blender 5.2.2 modifier parity now covers Simple Deform's axis/limit formulas, zero-thickness Solidify's duplicated shell, curve bevel tessellation, and order-sensitive Array/Mirror stacks.
- Blender curve round trips retain `Curve.twist_mode` and match minimum-twist beveled `to_mesh` point sets; Clamp To and Spline IK preserve Blender's disabled CUSTOM-space results, and Shrinkwrap TARGET_PROJECT now uses interpolated vertex-normal surfaces.
- Legacy Blender IK now applies Blender's square-root-normalized weights to combined position/orientation tasks; supported elbow and non-ellipse swing chains retain strict 1e-5 parity, while two-axis X/Z Swing ellipse limits report `constraint.ik.swing_ellipse_limit` as unsupported. Shrinkwrap TARGET_PROJECT continues to match the interpolated vertex-normal surface.

- Blender modifier round trips preserve bound Surface/Mesh/Laplacian Deform behavior after moving bound geometry; PC2/MDD/Alembic cache settings normalize Blender RNA arrays and match after reopening.
- Boolean modifier evaluation now dissolves adjacent coplanar fragments; round-trip coverage checks DIFFERENCE/UNION/INTERSECT with object/collection operands and EXACT/FLOAT solvers using closed-surface distance, volume, manifold, and component invariants. `pot inspect` reports evaluated mesh faces as vertex-index lists alongside positions.
- Restored the supported polygon-mask feature catalog entry for mask create, update, and delete operations; Bezier spline handles remain unsupported.
- Blender-gated COLLAPSE now preserves Blender's retained BMesh face normals when triangulating and matches strict topology/1e-5 position parity for the first-collapse boundary probe, triangulation, X symmetry, vertex groups, vertex-group factor 0.5, and a ratio-0.5 open grid. Inverted vertex-group COLLAPSE remains cataloged unsupported at every ratio below 1.0 after its ratio-0.7 probe diverged by one face/edge and 1.554746e-1 in vertex position.
- Decimate UNSUBDIV and DISSOLVE now follow Blender's `bmesh_decimate_unsubdivide` / `bmesh_decimate_dissolve` algorithms (BLI heap tie order, float32 angle/normal costs, delimit rules, degenerate-ear checks, edge-pair collapse order); Blender-gated fixtures assert identical topology and 1e-5 per-vertex parity for UNSUBDIV iterations 1–2 and DISSOLVE angle, NORMAL, MATERIAL, SEAM, SHARP, UV, and boundary settings (0.0 maximum vertex error).

- Native constraint evaluation now includes Action, Geometry Attribute, Camera Solver, Follow Track, and Object Solver constraints plus pose-bone Transform Cache constraints. Movie clips store source dimensions and scenes select an active clip for clip-based evaluation. Tracking objects persist per-frame reconstruction poses, and `tracking.solve_object` fits rotation and translation against solved projective cameras while preserving the seeded uniform scale because a single view cannot determine absolute scale.
- Physics systems now evaluate as frame-cached object-stack modifiers, so earlier geometry feeds cloth, soft body, particles, fluid, dynamic paint, and collision, while later modifiers run on the simulated result. Particle Instance and Explode realize particle-driven geometry; Volume Displace resamples inline scalar grids and single-grid VDB density from image/noise texture vectors in LOCAL, GLOBAL, or OBJECT coordinates. Physics modifiers link by settings ID rather than duplicating simulation settings.
- Particle states retain current and birth rotations, birth frames, and unborn/alive/dead lifecycle; Particle Instance evaluates LOCAL/WORLD coordinates, child/parent selection, size, and lifecycle visibility. Blender sampled-path mode is cataloged unsupported because cached path trajectories are not represented. Cloth has frame-one rest-state parity and fixture-specific aggregate checks; implicit-solver numerical parity remains unsupported. Catmull–Clark subdivision evaluates limit-surface positions and honors boundary smoothing, edge creases, and render levels. Object-solve initialization derives translation from reconstructed landmarks, while Follow Track depth objects cast against mesh geometry.
- Added bound Surface Deform with adjacent-polygon mean-value weights, voxel-grid harmonic Mesh Deform, rotation-invariant cotangent least-squares Laplacian Deform, Blender-compatible BLOCKS/SMOOTH/SHARP dual-contouring Remesh, and a seeded Tessendorf FFT Ocean. BLOCKS matches 432 vertices and 430 faces exactly; SMOOTH matches 432 vertices and 430 faces with 6.750077994e-7 maximum matched vertex error; SHARP matches 432 vertices and 430 faces with 7.305886004e-6 maximum matched vertex error. Strict Blender parity also covers UV spheres at depths 5/6, torus, a non-uniformly scaled/rotated object, scale 0.6, disconnected thresholds 1.0/0.3, and SHARP sharpness 0.5/2.0. Open Suzanne remains gated under `modifier.remesh.open_nonmanifold`: its pre-gate dense repair produced 424 BLOCKS vertices versus Blender's 422 because recursive patchSplit/connectFace repair remains incomplete. VOXEL matches Blender/OpenVDB topology and 1e-5 position parity at voxel sizes 0.1 and 0.05 with zero adaptivity (4728/18856 vertices, 4724/18852 faces, and 1.192092896e-7 maximum error); nonzero voxel adaptivity remains gated as `modifier.remesh.voxel_adaptivity`. Added modifier.bind/unbind and topology-preserving modifier.apply_as_shape_key; modifier.apply now rejects all shape-key meshes with Blender's equivalent guard.
- Added native evaluation for vertex-weight edit/mix/proximity, image texture masks, weighted/normal editing, UV project/warp, mesh-domain data transfer, and resource-backed PC2/MDD Mesh Cache interpolation.
- UV Warp now applies the full object-from/object-to transform with vertex-group influence; Mesh Cache matches Blender TIME/FACTOR sampling and triangle-relative INTEGRATE deformation. Blender depsgraph parity covers proximity EDGE/FACE falloffs, orthographic UV projection aspect/scale, and integrated PC2/MDD caches; weighted-normal comparisons round-trip loop normals through Blender's short2 storage before a 1e-5-radian comparison.
- Blender imports retain TextCurve data and external font references, represent file-backed VDB volumes as editable graph data with grid names and reported bounds, and preserve sequencer strip names. Referenced fonts, movies, images, sounds, and VDB files are hash-checked and copied into the project asset store by default; link policy records external dependencies. Blender exports use original asset filenames in sidecars, add content suffixes only for filename collisions, and attempt to pack fonts when requested.
- The read-only OpenVDB reader decodes sparse float and vec3 grids, half-float values, supported transforms, raw/ZIP data, and Blosc LZ4/LZ4HC, zlib, and zstd blocks using pure-Rust codecs. Beauty, solid, wire, path-render, and volume-to-mesh evaluation use VDB content; bit-shuffled Blosc buffers and other unsupported OpenVDB variants report typed feature errors.
- VDB and inline volume density is treated as extinction in 1/m and integrated with Beer–Lambert transmittance using the scene unit scale. Path and real-time camera renders preserve the empty-scene background outside the sampled density footprint.
- Path volume rendering now samples heterogeneous extinction and Henyey-Greenstein scattering events, estimates direct light and environment in-scattering, and integrates volume emission. Realtime beauty previews composite a fixed-step lit single-scattering approximation with transmittance-weighted light marches.

- Alembic Mesh Sequence Cache now round-trips through Blender with copied cache resources, original filenames in sidecars, frame/scale/override settings, attribute flags, interpolation, and scaled velocity attributes. Native Transform Cache constraints evaluate sampled cumulative Alembic Xforms and are recreated on export.

- Blender library import now projects linked objects, data blocks, materials, collections, actions, node groups, worlds, and image resources as read-only linked graph items; it retains Blender library overrides, reports missing dependencies, validates copied resources, and re-exports linked IDs and override values without flattening them. Library files and nested dependencies are restored as sidecars.
- Fixed Blender library paths: relative `Library.filepath` values now resolve against the linking file (parent library or main file) instead of the library itself, and exported library sidecars keep their relative directory layout so nested relative links stay valid.

- Fixed `.blend` round-trip rig support: bone rolls are read from edit-mode bones via a temporary armature probe, vertex-group/shape-key/bone potter IDs are stored as namespaced JSON custom properties (`potter.vertex_group_ids_json`, `potter.shape_key_ids_json`, `potter.bone_ids_json`) instead of unsupported IDProperties, armature modifiers resolve their target object on export, and pose quaternions round-trip in Blender's (w, x, y, z) order.
- Blender pose-bone constraints are graph-owned via `owner_bone`, schema-validated against the owning armature, visible in `inspect`, and evaluated on bone matrices in armature space (IK and spline IK retain chain semantics). Supported constraints export from the canonical graph; unsupported pose constraints remain in compatibility data and report loss.
- Exported `.blend` animations, object constraints, drivers, modifier stacks, NLA tracks, and material/world shader graphs now write the canonical potter graph instead of stale compatibility payload (spec §11); compatibility data only fills unknown detail (handles, F-Curve modifiers, constraint/NLA custom properties, properties the graph does not model).
- Fresh potter scenes export with correct static transforms (lowercase `quaternion` rotation mode no longer aborts transform restoration), and delta transforms from compatibility metadata are restored as RNA values.
- Root nodes with a non-TRS `parent_inverse` export using Blender's closest loc/rot/scale basis; exact parent_inverse/local transform are stored in `potter.root_matrix_json` and restored on import while the baked basis is unchanged. Blender edits invalidate the marker and import their current basis; the approximation is reported in export conversions.
- All potter primitive descriptors (box, sphere, cylinder, cone, torus, plane, icosphere, circle, grid) export as editable Blender meshes with the descriptor kept in `potter.descriptor_json` and restored on import; no `--allow-lossy` required.

- Added deterministic cached cloth and soft-body deformation, seeded mesh particle emission, SPH liquid domains with metaball surfaces, and brush-proximity dynamic paint.
- Added create/update/delete physics operations and per-frame simulation bake payloads for these systems. Smoke/fire fluids and simulation nodes remain unsupported.
- Added directional world shader evaluation, equirectangular environment importance sampling, analytic sky shading, volume extinction/scattering, displacement bump/subdivision, deterministic realtime GGX raster shading with BVH PCF shadows and AO, alpha blending/clipping, panorama/fisheye/stereo cameras, depth of field, and shutter-sampled motion blur.
- Stabilized canonical scene hashes across save/load by avoiding repeat normalization of already unit-length quaternions.
- Added `node.delete` reparent policies (`to_parent`/`to_root`) with world-transform preservation by default, and aligned camera/light creation with common node fields including tags.
- `pot inspect` now separates local evaluated `transform.evaluated.matrix` from world `transform.world` placement and reports whether the world matrix is safely decomposable, preserving the matrix when shear or singularity prevents TRS decomposition.

- Feature catalog now marks bone collections/custom shapes/envelopes, absolute shape keys, difference drivers, NURBS and multi-spline IK, and the fixed basic-human Rigify-lite generator as supported; full Rigify metarig generation and metadata remain unsupported.
- `image.load` decodes JPEG, TIFF (8/16-bit and floating-point), OpenEXR, WebP, BMP, TGA, Radiance HDR, and 16-bit PNG into f64 RGBA. Eight-bit rasters default to sRGB; HDR/EXR/float TIFF default to linear. EXR selects Combined/RGBA or the first RGB layer and unpremultiplies its RGB values into straight-alpha storage; `srgb`, `linear`, and `non_color` overrides are honored.
- Fixed Blender transform import for Euler-rotated objects by serializing Euler components numerically and matching Blender's Euler rotation order; Blender-gated parity coverage checks local/world matrices for all Euler orders, quaternion, and axis-angle rotations, plus rotated global Displace and object-offset Array fixtures.
- Array modifiers now add transformed start/end cap meshes with threshold merging, fit copies to scaled evaluated curve paths, and offset UV layers per copy; Blender-gated import/export fixtures cover caps, FIT_CURVE, and UV offsets.
- Blender-gated Wireframe and Skin chain round trips meet 1e-5 per-vertex parity, with Skin radii and roots keyed by vertex ordinal. Skin branch-hull evaluation is cataloged `not_supported` and `pot inspect` returns `UnsupportedFeature` rather than divergent geometry; the branch-smoothing 0.35 fixture measured a 4.368013e-2 maximum vertex gap before the cutover, and a second branch fixture exercises X symmetry. `.blend` export preserves the live branch Skin modifier without native evaluation, with round-trip checks for modifier settings and Blender-evaluated topology/positions. Mesh-to-Volume Volume owners evaluate leaf-aligned fog grids in VOXEL_SIZE and VOXEL_AMOUNT modes; round-trip checks compare grid metadata, bounds, and OpenVDB density probes.
- Catmull–Clark boundary-corner limit samples now match Blender's quality-dependent refinement without changing topology; shape-key capture coverage now uses a wave stimulus that actually deforms the fixture.

- Blender simulation modifier round trips now retain writable settings RNA, cloth collision settings, Dynamic Paint roles/surfaces, fluid domain/flow/effector settings, and point-cache ranges/baked state; guarded Blender fixtures assert exact frame-one geometry where parity is established, the cloth solver-parity catalog limitation, and reopened settings/evaluation.
- Added Blender-gated round-trip coverage for every mapped constraint on object and pose-bone owners, animated depsgraph matrices, nondefault spaces/mix modes, MovieClip reconstruction, and Object Solver inverses; Transform Cache generic RNA settings and Armature target collections are preserved by the adapter.
- Blender constraint evaluation honors connected-bone head anchoring, target-bone head/tail offsets, Copy Rotation/Copy Transforms mix modes, Blender rotation-limit flags, and Child Of channel masks; export restores Blender 5.2 Matrix RNA and keyword-only MovieClip markers.
- Blender UV Project now uses evaluated owner/projector transforms and camera sensor/shift projection; UV Warp transform composition, Data Transfer loop masks/topology, and round-trip parity for attribute, deform, remesh, Ocean, and PC2/MDD/Alembic cache modifiers are covered.
- Blender constraint evaluation converts owner and target matrices through independent WORLD/LOCAL/POSE/LOCAL_WITH_PARENT/CUSTOM spaces and matches tracking/up-axis and target-Z behavior, Stretch To rest-length/volume/keep-axis, Limit Distance modes, Pivot rotation ranges, and Transformation map/mix/Euler/extrapolation.
- Blender B-Bone segment settings and custom handles round-trip through armature bones; segmented B-Bone constraint target sampling and weighted Armature modifier/constraint deformation return catalogued UnsupportedFeature instead of linear-transform approximations.
- Blender Transform Cache honors Alembic root CacheFile scale; export preserves CacheFile identity and pose-bone rotation modes, Armature zero-envelope constraints remain unchanged, and Camera Solver uses reconstructed camera transforms directly.
- Blender Follow Path evaluates animated offset factors and curve-follow axes at strict 1e-5 matrix parity; constraints in CUSTOM owner/target spaces that Blender disables remain unchanged.
- Blender MovieClip export reuses unchanged native clips instead of re-solving read-only reconstruction data; Potter-authored or changed reconstruction reports `blender.movieclip.reconstruction`, while `--allow-lossy` preserves writable tracks, markers, and calibration. Object Solver restoration retains the inverse-set frame and matches evaluated matrices.
